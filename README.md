# ChargebackGuard

A merchant dispute management portal designed to help sellers manage chargeback disputes, submit evidence, track response deadlines, receive reminders, and handle escalations.

## Problem Statement

Razorpay wants a merchant dispute portal where sellers upload evidence against chargebacks. Each dispute has a 7-day timer; merchants get daily reminders, and cases auto-escalate if no response. All evidence must be stored immutably.

## Project Objective

ChargebackGuard aims to provide merchants with a centralized portal for managing disputes and responding to chargebacks within the required time period.

## Core Features

* Merchant dispute dashboard
* Dispute details and status tracking
* 7-day response deadline
* Evidence upload and submission
* Daily deadline reminders
* Automatic escalation for unanswered disputes
* Immutable evidence records
* Admin monitoring of disputes

## Tech Stack

* Next.js — Full-stack React framework
* PostgreSQL — Relational database
* Prisma — ORM for TypeScript
* GCP — Cloud platform and hosting
* GitHub Actions — CI/CD automation

## Development Workflow

* Each team member works on a separate branch.
* Changes are submitted through pull requests.
* Team members review PRs before merging.
* The main branch contains the stable version of the project.
